## Hi, I'm Germán

Engineer. Former CTO and CISO in European payments. These days I work independently with regulated and technology companies, and build coderoom. More at [g18a.com](https://g18a.com).

## What I care about

SDLC is supposed to help teams move fast without breaking things. Most of the time it just adds bureaucracy, and quality slips anyway. I think the fix comes from within engineering:
start with what teams already do every day (code reviews, tests, vulnerability scans, deployments) and turn it into evidence, instead of adding process on top.

AI agents raise the stakes. They move fast and touch sensitive systems, and when one causes an incident, the root cause is usually a weak basic control it amplified: loose access,
easy privilege escalation, thin monitoring. So I want loops with limits, checks that decide when the work is done, and the engineer in charge.

## Right now

**coderoom**: script your agents like you script your shell. An open-source shell for coding agents, built around those limits and checks. [Why I built it](https://g18a.com/coderoom/).
